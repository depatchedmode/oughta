# Sharpen Plan

Apply the following prompt to the user's existing plan or task prompt. Preserve its objective, scope, constraints, and deliverable. Choose practices that materially improve the task; avoid expert role-play and unnecessary process. Ground the four answers in available primary evidence, and distinguish required inputs and tools from those actually available.

> I want a deeper version of this task, not a bigger one. Before rewriting it: (1) say what a top professional in this field would do here that I’m not asking for; (2) name the rawest material they would start from instead of what has already been digested for me; (3) name the specific methods and tools they would use; (4) say what, other than you or me, would show the result is right. Then rewrite my prompt to ask for exactly that.

Return four numbered answers followed by a standalone rewritten prompt. Do not execute the rewritten task unless separately requested.
